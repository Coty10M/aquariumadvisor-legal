# AquariumAdvisor Legal Site

This folder is ready for GitHub Pages.

## Publish
1. Create a **public** GitHub repository, for example `aquariumadvisor-legal`.
2. Upload `index.html`, `privacy.html`, `terms.html`, and `style.css` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then **Save**.
6. Wait for GitHub Pages to publish.

Your URLs will look like:

- `https://YOUR-GITHUB-USERNAME.github.io/aquariumadvisor-legal/privacy.html`
- `https://YOUR-GITHUB-USERNAME.github.io/aquariumadvisor-legal/terms.html`

For App Store Connect, use the `privacy.html` URL as the Privacy Policy URL.
For the EULA, AquariumAdvisor uses Apple's standard EULA:
https://www.apple.com/legal/internet-services/itunes/dev/stdeula/
